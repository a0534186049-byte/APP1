# ספירה לאחור לחתונה

אפליקציית Android מקורית ב-Kotlin עם ממשק מלא בעברית ו-RTL, שלוש ערכות רקע מקוריות שחולצו מקובץ הרקעים שסופק, תאריך עברי, תמונה אישית, שומר מסך, טפט חי ושני ווידג'טים למסך הבית.

## עיקרי הממשק
- שם האפליקציה: ספירה לאחור לחתונה.
- מסך ראשי מינימלי: רקע העיצוב הפעיל, כותרת אירוע לפי בחירה, קוביות זמן ותאריך עברי עם שעה.
- שלוש ערכות מובנות: יוקרה בזהב, מעבר צבעים מודרני, תלת־ממד פרימיום.
- תמונה אישית נבחרת דרך בורר המסמכים של Android ונשמרת לשימוש מקומי ללא אינטרנט.
- מראה קוביות כהה, בהיר או זכוכית חלבית מוצג רק כאשר תמונה אישית פעילה.
- בחירת תאריך ושעה דרך לוח עברי. התאריך הפנימי נשמר כשנה/חודש/יום עבריים.
- הגדרות במסך מלא ייעודי, מחולקות לקבוצות.
- ווידג'טים: עם כותרת וללא כותרת.
- שומר מסך וטפט חי נשארו בפרויקט ומשתמשים באותו מנגנון הציור.
- תכונות צליל ומצב מסך מלא לממשק האפליקציה הוסרו.
- אין הרשאת INTERNET או שליחת נתונים החוצה.

## הורדת APK
1. פותחים את Actions: https://github.com/a0534186049-byte/APP1/actions
2. בוחרים ריצה ירוקה של Android APK.
3. לאחר מיזוג השינוי ל-main, מורידים את app-release.apk מה־Release הקבוע: https://github.com/a0534186049-byte/APP1/releases/tag/latest-apk

## בנייה
הבנייה נעשית עם JDK 17, Gradle 8.13 ו-Android SDK Platform 36. פקודת CI:
gradle --no-daemon clean testDebugUnitTest assembleDebug assembleRelease

ה־CI בודק את בדיקות היחידה, את החתימה ואת גודל כל APK (מתחת ל-30,000,000 בתים). בדיקת בנייה אינה מחליפה התקנה ובדיקה במכשיר אמיתי; יש לאמת בפועל את בחירת התמונה, לוח השנה, הווידג'טים, שומר המסך והטפט החי על המכשיר המיועד.
