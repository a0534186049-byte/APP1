# ספירה לאחור לאירוע — Neon Event Countdown

אפליקציית Android מקורית ב-Kotlin עם ממשק עברי ו-RTL, עיצוב ניאון מבוסס Canvas ושמירת העדפות מקומית. אין הרשאת `INTERNET`, אין SDK פרסומי ואין שליחת נתונים החוצה.

## מה כלול
- בחירת תאריך יעד ותאריך עם שעה מדויקת, או תאריך בלבד.
- ימים, שעות, דקות ושניות, עם בחירה אילו יחידות להציג.
- כותרת לאירוע, ערכות צבע, צבע מוביל, עוצמת זוהר ומהירות אנימציה.
- שלוש התנהגויות בסיום וצליל סיום אופציונלי (כבוי כברירת מחדל).
- מצב מסך מלא, DreamService לשומר מסך ו-WallpaperService לרקע חי.
- שמירת נתונים ב-SharedPreferences וחישוב מחדש משעון המערכת. אין שירות קבוע לצורך עדכון התצוגה.
- בדיקות יחידה לחישוב הזמן שנותר ובניית Debug/Release אוטומטית.

## קבלת APK מוכן דרך GitHub
1. פותחים את לשונית **Actions** במאגר: https://github.com/a0534186049-byte/APP1/actions
2. בוחרים את הריצה האחרונה של **Android APK** שמסומנת בירוק.
3. בתחתית פרטי הריצה פותחים את **Artifacts** ולוחצים על `neon-countdown-apks`.
4. פותחים את קובץ ה-ZIP שהורד. בתוכו יהיו `app-debug.apk` ו-`app-release.apk`.
5. מעבירים את אחד מקובצי ה-APK למכשיר Android ופותחים אותו להתקנה. ייתכן שיהיה צורך לאשר התקנת אפליקציות מהדפדפן/מנהל הקבצים.

אם אין Artifact, או שהריצה אדומה, הבנייה לא הושלמה בהצלחה. יש לפתוח את שלב השגיאה (לוג) במקום להתקין APK ישן.

## בנייה מקומית
דרושים JDK 17, Gradle 8.13 ו-Android SDK Platform 36 עם Build Tools 36.0.0.

מתיקיית הפרויקט:
```bash
gradle --no-daemon testDebugUnitTest assembleDebug assembleRelease
```

הקבצים יהיו תחת:
- `app/build/outputs/apk/debug/app-debug.apk`
- `app/build/outputs/apk/release/app-release.apk`

## חתימת Release ועדכונים
GitHub Actions חותם את ה-APK כדי שיהיה ניתן להתקין אותו. אם לא מוגדר מפתח חתימה קבוע, נוצר מפתח זמני לכל ריצה: ה-APK מתאים להתקנה, אך APK חדש לא יוכל לעדכן התקנה קודמת באותו Package Name בלי להסיר את הגרסה הישנה. כדי לפרסם עדכונים לציבור, יש ליצור מפתח פרטי קבוע ולשמור אותו ב-GitHub Repository Secrets בשם `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, ו-`ANDROID_KEY_ALIAS`. לעולם אין להעלות את קובץ המפתח למאגר ציבורי.

## הרשאות ומגבלות
- במניפסט אין הרשאת אינטרנט. ההרשאה היחידה שנדרשת לאפליקציה היא `RECEIVE_BOOT_COMPLETED` כדי לתזמן מחדש צליל סיום לאחר הפעלה מחדש.
- צליל הסיום כבוי כברירת מחדל. כשהוא מופעל, Android מקבל AlarmManager לא-מדויק, ולכן מצב חיסכון בסוללה או מגבלות יצרן עלולים לעכב את הצליל.
- תמיכה בפועל בשומר מסך וברקע חי תלויה בגרסת Android, במפעיל וביצרן המכשיר. האפליקציה פותחת את מסך המערכת המתאים, אך אינה יכולה להבטיח שהיצרן מאפשר כל מצב.
- סף גודל APK של 30,000,000 בייט נאכף ב-GitHub Actions. תוצאות הבנייה ובדיקות היחידה יופיעו בלוגים של הפעולה.
- בניית CI בלבד אינה מוכיחה התקנה או פעולה תקינה על חומרה אמיתית. נדרשת בדיקת התקנה על מכשיר/אמולטור לאחר הורדת ה-APK.
